Como rodar localmente:

  2. Back-end:   cd server && cp .env.example .env && npm install && npm run seed && npm run dev
  3. Front-end:  cp .env.example .env.local && npm install && npm run dev
  4. Telemetria ao vivo (opcional): cd server && npm run simulate
